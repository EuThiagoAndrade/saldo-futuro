# Ponte neutra de tarefas

Não há ponte operacional ativa neste arquivo.

O estado real de cada implementação é registrado em uma task persistente: no diretório do ciclo (em `_project/drafts/` enquanto ativo e em `_project/executed/` após o encerramento) ou, na trilha curta, em `_project/fixes/`. Issues, pull requests e checks têm como autoridade externa o GitHub.
